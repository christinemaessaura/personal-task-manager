## How It Works/ Step by Step

### 1. View Tasks

The user can view all saved tasks on the main task list. Each task displays its name, description, status, and due date. The user can also edit, delete, or change the task status.

![Task List](screenshots/task-list.png)

### 2. Add a Task

The user clicks "Add New Task" and enters the task name, description, and due date. After clicking "Add Task," the task is saved and added to the task list.

![Add Task](screenshots/add-task.png)

### 3. Edit a Task

The user can click "Edit" on an existing task to update its name, description, status, or due date. Clicking "Update Task" saves the changes.

![Edit Task](screenshots/edit-task.png)

### 4. Manage Task Status

Tasks can have either Pending or Completed status. The user can change the status directly from the task list or through the Edit Task page.

### 5. Delete a Task

The user can click "Delete" on a task to remove it from the task list.
